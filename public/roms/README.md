# Bundled demo ROM

`gothicvania.sfc` is a **license-friendly homebrew game** included so the
player can be tested end-to-end without downloading a commercial ROM.

| | |
|---|---|
| **Game** | Gothicvania — a graveyard action-platformer demo |
| **Author** | Tom D ([donth77/snes-homebrew](https://github.com/donth77/snes-homebrew)) |
| **Release** | [v1.0.0](https://github.com/donth77/snes-homebrew/releases/tag/v1.0.0) |
| **License** | MIT (see [`LICENSE`](./LICENSE)) |
| **ROM** | LoROM, 512 KB, no copier header |
| **SHA-256** | `11d32045c69839309490676fe2dd46e3385806f79c8dad279c2d1f4ffa6027df` |
| **CRC32** | `88D63376` |

The game is built with [PVSnesLib](https://github.com/alekmaul/pvsneslib).
Art is adapted from the **GothicVania Cemetery** pack by
[ansimuz](https://ansimuz.itch.io/gothicvania-cemetery), released under **CC0**.

This directory contains **no commercial ROMs**. The operator supplies their
own dumps for the rest of the catalog.
